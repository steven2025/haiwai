# 澜桥面试 · GitHub 发布文件

本目录是前端发布副本。上传本目录内的全部文件及 assets 目录到 GitHub 仓库根目录，保留目录结构；不要再套一层 GITHUB发布页 文件夹。

当前前端：v8.1，新增简历导入、DOCX模板、模拟岗位推荐、韩语及印尼语；包含统一问题结构、岗位评价权重、证据化维度评分；包含大字号连续字幕、小屏独立滚动、真人双向字幕与译音、可视化双语报告和腾讯云实时回答识别。真人同传需要部署 v8.1 云函数并设置 RTC_ENABLE_AI=true，法语、西班牙语默认使用 flow_01_ex。GitHub Pages 只托管静态页面，云函数与私有 COS 存储单独配置。

本目录不含 server、云函数源码、密钥、环境变量或本地面试记录。不要另行把这些私密文件复制进来。

网页部署后，将准确的网站来源加入云函数 ALLOWED_ORIGIN，例如 https://你的用户名.github.io ，不包含仓库路径。

维护源文件在上一级目录。每次修改后，在上一级目录执行 node 同步GITHUB发布页.cjs 更新本目录；不要只修改发布副本。
